# audit 설치·업데이트 지침 (에이전트용)

> 사용자는 이 폴더(`~/harness/audit`)에서 Claude Code를 켜고 "SETUP_FOR_AGENT.md 읽고 설치해줘"라고 하거나, 어디서든 "audit 업데이트해줘"라고 한다.
> 사용자는 비전공자다. 쉬운 한국어로 짧게 알린다. 여러 번 실행해도 안전하다.
> audit은 전역 설치다(`~/.claude/agents`, `~/.claude/commands`). 모든 프로젝트에 영향을 주므로 **기존 파일을 판단 없이 덮어쓰지 않는다.** 판단은 스크립트가 한다.

1. **점검(사전 검사):** `node ~/harness/audit/install.mjs` 를 실행하고 결과를 그대로 보여준다. (아무것도 바꾸지 않음) **[멈춤]이 하나라도 나오면(exit 1) 그 자리에서 멈추고, 모든 항목을 한 메시지로 보여주고 묻는다. 답을 받기 전에는 어떤 파일도 만들거나 바꾸지 않는다.**
2. **안전한 것 적용:** "없음 → 설치", "옛 버전 → 교체"가 있으면 무엇을 할지 한 줄로 말하고 `node ~/harness/audit/install.mjs --apply` 를 실행한다. 기존 파일은 `~/harness/audit/.backup/<시각>/`에 백업된다.
3. **건너뛴 파일:** 스크립트가 "건너뜀"으로 보여준 파일은 직접 덮어쓰지 않는다. 파일마다 harness 원본과의 차이를 보여주고 묻는다.
    - "원본 이력에 없는 줄"(직접 고쳤거나 이력 이전의 옛 버전): 그 줄이 쓸 만하면 **설치본이 아니라 harness 원본(`~/harness/audit/...`)에 반영할지** 묻는다. 원본을 고쳤으면 커밋 후 1단계부터 다시. 버려도 되면 `--apply --replace <파일 이름>`.
    - "이름만 같은 다른 도구 파일": 그 도구를 계속 쓸지 묻는다. 쓴다면 audit 쪽을 설치하지 않고 이름 충돌을 알린다. 안 쓴다면 `--apply --replace <파일 이름>`.
    - 원본에 반영하지 않고 설치본에만 합치지 않는다. 원본이 둘이 되어 다음 설치 때 사라지고, 측정한 버전과 달라진다.
4. **이름 겹침 [멈춤]:** 같은 이름의 스킬(`~/.claude/skills/...`), 플러그인(`~/.claude/plugins/...`)의 같은 이름 명령·에이전트, deep-audit 사본이 있으면 `--apply`도 아무것도 바꾸지 않는다. 어느 쪽을 남길지 묻고, 치울 때는 지우지 말고 `~/harness/audit/.backup/`으로 옮긴다(플러그인은 플러그인 관리 화면에서 끄기). 그 뒤 1단계부터 다시.
5. Claude Code의 안전장치에 막히면 우회하지 말고, README.md의 "막히면 직접 복사" 방법을 안내한다. 이때도 같은 이름 파일이 있으면 먼저 백업하게 한다.
6. 보고 (3줄 이내):
    - 설치·교체한 것 / 건너뛴 것
    - "Claude Code를 다시 켜고 `/audit`을 쳐서 명령 세 개가 보이면 끝이에요."
    - 백업 위치 (있을 때)

`~/harness/audit` 폴더는 원본이므로 지우지 않는다.
